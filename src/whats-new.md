## v4.0 - 2026 Sep 28
- 8 new languages (Bhojpuri, Ho, Konkani, Rohingya, Saurashtra, Sindhi, Sylheti, Tulu), 7 new scripts (Hanifi Rohingya, Kaithi, Meetei Mayek, Saurashtra, Sharada, Syloti Nagri, Warang Citi), new layouts for Assamese, Hindi, Kashmiri, Maithili, Manipuri, Marathi, Odia, Punjabi, Sinhala, Telugu and Urdu
- Gesture typing, built in; works on transliteration layouts too
- Companion typing: suggestions in a second language while typing English, no switching needed.
- Predictive transliteration (Varnam) for 13 languages, inline typing
- Language packs: dictionaries download per language and script, smaller app
- Next-word prediction for 20 languages, spell check, words from Wikipedia, Olam and Alar
- Transliteration: backspace edits a word key by key, option to show the typed Latin word
- Clipboard history with images, recent copy in the suggestion strip, configurable auto-clear
- Password manager autofill in the suggestion strip
- Physical keyboard support
- Themes: Material You (dynamic colours), Material 3 light and dark. Live previews, follows system dark mode
- Emoji overhaul: better search, default skin tone, ZWJ emoji, bigger recents, optional emoji key
- Language switching: layouts grouped by language, native language name on the space bar, globe key stays in the keyboard, option to hide it
- Redesigned settings, setup wizard and About page, layout previews, per-language settings, prompt to switch back when another keyboard takes over
- Privacy page: browse and delete learned words, toggle for learning, dim suggestions in incognito
- Per-language numerals, auto space after danda and other full stops
- Dedicated number pad, rearranged symbols, Inscript function key and symbols layer
- Tablets: phone layouts, two-pane settings, sizing fixes
- Offline build: all language packs bundled, no internet permission
- Android 17, direct boot, 16 KB page size devices; now needs Android 5.0 or newer
